# MagicFlow suite · marketplace di Adà per Claude

Questo è il marketplace dei plugin di **Adà Srl** per Claude.

**Per installare MagicFlow suite:**
1. in Claude, aggiungi il marketplace `genialada/magicflow-suite` e attiva l'aggiornamento automatico;
2. installa **MagicFlow suite** (in Claude Code: `/plugin install magicflow-suite --marketplace genialada/magicflow-suite`);
3. scrivi **«attiva MagicFlow»**: Claude ti guida a collegare il tuo codice di licenza.

Il codice di licenza arriva con l'acquisto su [genialada.com](https://genialada.com). Senza un codice valido il
plugin non lavora: istruzioni e programmi arrivano dal server di Adà solo a chi ha una licenza attiva.
